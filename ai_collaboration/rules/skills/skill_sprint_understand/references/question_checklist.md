## 2. 场景化问题清单

### 2.1 新增模块场景

- [ ] 模块与其他模块的关系是什么？
- [ ] 模块的核心实体有哪些？
- [ ] 模块的状态流转是什么？
- [ ] 是否需要配置项？
- [ ] 是否需要定时任务？

- [ ] 接口的调用方是谁？

- [ ] 接口的限流策略是什么？

- [ ] 源数据的格式是什么？
- [ ] 数据映射规则是什么？

- [ ] 当前性能瓶颈在哪里？
